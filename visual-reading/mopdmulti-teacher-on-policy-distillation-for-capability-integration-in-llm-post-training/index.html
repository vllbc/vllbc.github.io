MOPD：把多个领域 RL 教师蒸馏进一个学生

先在通用 SFT 模型上给每个领域单独跑 RL，得到 Math、IF、SWE 等专家；再让学生自己生成轨迹，每个 prompt 按领域路由到对应教师，教师 prefill 后给出逐 token log-prob，学生用 reverse KL 更新。Qwen3-30B-A3B 上归一化分数 0.9373，比最强基线 Mix-RL 的 0.8818 高约 5.55 个百分点。

Wenhan Ma、Jianyu Wei、Liang Zhao 等 · 北京大学 / 小米 LLM Core / 香港大学 / 中国人民大学 原文 ↗
TL;DR · 30 秒抓住核心

多领域后训练常见有四类做法：把各领域数据混在一起联合 RL、按领域依次训练、在教师轨迹上做离线 SFT、合并教师权重。联合 RL 会出现 see-saw，串行训练会让先训练的能力在后续阶段衰减，离线 SFT 有 exposure bias，权重合并也不稳定。MOPD 把整合搬到策略空间：教师只负责给分，学生始终在自己的分布上训练。

三阶段是：General SFT 得到共享起点；每个领域从同一 SFT checkpoint 独立跑 RL，得到若干冻结教师；学生从同一 SFT checkpoint 初始化，对混合 prompt 自己 rollout，按 prompt 的领域路由到对应教师，最小化逐 token reverse KL。论文在 Qwen3-30B-A3B 上比较 Mix-RL、Cascade RL、Off-Policy Finetune、Param-Merge 与 MOPD，并在 MiMo-V2-Flash（309B）上跑完整流水线。

关键结果：MOPD 的归一化分数 0.9373，三个领域的分差只有 0.044；同源教师下 PG 与 Top-K 两种实现接近（0.9373 对 0.9093）；把 Math 教师换成更强的 Qwen3-235B-A22B 后反而退化，说明教师与学生的分布对齐比教师绝对能力更重要。

01

单领域 RL 很强，但“合成一个模型”本身是另一个问题

读完这节应该知道：为什么把多个领域专家的能力放进同一个学生，不是简单地把数据混在一起再训一遍。

论文把当前后训练拆成几条不同的 RL 流水线：数学用可验证答案的 RL，软件工程用在可执行沙箱里的 agent-style RL，指令跟随和创意写作用 rubric-based RL，搜索 agent 用 web-environment RL。每条流水线都能在自己的领域里把模型推得更远，但最终要的是一个模型同时会这些事。

难点不只是数据量。不同领域的 reward 形状、rollout 长度、环境交互方式都不同；把它们放进同一个训练循环，梯度会互相干扰，出现 see-saw effect：一个领域的分数上升，另一个领域下降。若改成串行训练，后一阶段又会改变前一阶段学到的策略。论文把这类取舍归纳为三个轴：dense optimization、on-policy training、parallelisable pipeline（Table 1）。

信号密度

轨迹级 reward 还是逐 token 监督

普通 RL 只在轨迹结束给一个 outcome reward；蒸馏可以在每个 token 位置给出教师分布，信号更密，方差更低。

分布匹配

训练分布是不是学生自己的

离线 SFT 用教师轨迹训练，学生推理时会走到教师没覆盖的状态；on-policy 训练始终用学生自己的 rollout。

工程并行

领域团队能不能独立迭代

联合 RL 或串行 RL 把领域耦合在一个长任务里；如果教师训练彼此独立，某个领域调参或重启不会阻塞其他领域。

所以问题可以写成：给定一组已经训练好的领域专家 {πφd}，如何得到一个学生 πθ，使它在每个领域都接近对应专家，同时不牺牲其他领域？论文的答案是：不要合并权重，也不要模仿教师轨迹，而是让学生自己采样，让教师在自己的轨迹上逐 token 打分。

每条路线具体卡在哪

Mix-RL

联合训练，信号互相拉扯

所有领域 prompt 放进一个 batch，每个样本仍用自己的 reward 和 advantage。论文指出跨领域训练信号会干扰，产生 see-saw effect；Table 2 中它是最平衡的基线（领域间极差 0.064），但整体仍比 MOPD 低 5.55 个百分点。

Cascade RL

串行训练，后面的阶段改前面的策略

按 IF → Math → SWE 顺序训练。论文报告第一段 IF 关闭了 98% 的 headroom，第二段 Math 只关闭 57%；Figure 2 还显示 Math 准确率在后续 SWE 阶段下降。这里论文用的是“可能衰减”，没有把它写成所有能力都灾难性遗忘。

Off-Policy Finetune

教师轨迹上的 SFT

先训练领域教师，再用教师生成的轨迹做离线 SFT。论文把问题归为 exposure bias：学生训练时看到的是教师分布，推理时却走自己的分布。Table 2 中它在 IF 上超过教师（归一化 1.01），但 SWE 只关闭 65% 的 headroom（相对教师 1.0；归一化分数 0.649）。

Param-Merge

权重空间融合

直接平均教师权重或做 task arithmetic。简单平均的归一化分数只有 0.3280，Task Arithmetic 回升到 0.8574，但每个领域的表现随合并系数和 benchmark 大幅变化；论文据此认为参数合并不够可靠。

03

学生采样，教师只给逐 token 的 log-prob，目标是 reverse KL

方法的核心不是新 RL 算法，而是把“多教师整合”写成一个按 prompt 路由的 on-policy 蒸馏目标。

设学生为 πθ，领域 d 的冻结教师为 πφd。对每个 prompt x，先按它的领域选一个教师；学生生成一条轨迹 y ∼ πθ(·|x)，教师在同一轨迹上 prefill，得到每个位置的概率分布。目标是最小化逐 token 的 reverse KL：

Lrev-KL = Ex, y∼πθ[ (1/|y|) Σt Σv πθ(v) log( πθ(v) / πφd(v) ) ]
Eq. 1：πθ(v) 与 πφd(v) 都是 π(v | x, y<t) 的简写；期望在学生的轨迹上取，不是教师轨迹。

这个目标有两个直接后果。第一，训练分布始终是学生自己的，所以不会出现离线 SFT 的 exposure bias。第二，教师在每个 token 位置给出完整分布，监督信号比轨迹级 reward 密得多；论文把这两点分别称为 no exposure bias 与 dense per-token supervision。

实现一：policy-gradient 形式

把 reverse KL 的梯度写成策略梯度，教师与学生的 log-prob 差就是逐 token advantage：

ÂMOPD,t = sg[ log πφd(yt) − log πθ(yt) ]
ÂclipMOPD,t = clip( ÂMOPD,t, −Amax, +Amax )
LPGMOPD(θ) = −Ex,y[ (1/|y|) Σt ÂclipMOPD,t log πθ(yt) ]
Eq. 2–4：sg 表示 stop-gradient；默认 Amax = 5（Appendix A）。这个形式只改 advantage 计算，可以直接塞进 PPO/GRPO 训练框架。

直观上，学生在某个 token 上的概率低于教师，log 差为正，梯度会把该 token 的概率往上推；高于教师则相反。它只用到采样到的那一个 token，因此实现简单，但每个位置只利用教师分布的一个点。

实现二：Top-K 形式

另一个选择是只在教师概率最高的 k 个 token 上蒸馏，k 默认 64。设 Tdt 为教师在位置 t 的 top-k token 集合：

LTopKMOPD(θ) = Ex,y[ (1/|y|) Σt Σv∈Tdt ( πθ(v) log( πθ(v) / πφd(v) ) − πθ(v) + πφd(v) ) ]
Eq. 5：最后两项 −πθ(v)+πφd(v) 是截断偏差修正项；论文说没有它，naive top-k reverse KL 在 πθ = πφd 时不一定取到最小值。

Top-K 的工程价值是传输量小：教师只需返回 top-k token 的 logits，不必把整个词表分布每个 token 都发给训练器，因而可以像轻量 reward 一样传递。论文的消融显示，同源教师下它的整体分数是 0.9093，低于 PG 的 0.9373，差距约 2.8 个百分点；在 Math 上两者接近，IF 和 SWE 略低。

路由规则

一个 prompt 只由一个教师打分

第 3 阶段每个 batch 从多领域数据集采样；轨迹按 prompt 所属领域 dispatch 到对应教师，教师冻结，只提供 log-prob。这个设计保证 loss 归属明确：Math prompt 不会被 IF 教师打分，SWE prompt 也不会被 Math 教师拉走。论文还把每个领域教师部署成独立的 prefill 服务，异步返回结果。

04

贵在 Stage 2 的领域 RL，Stage 3 的教师 prefill 被采样掩盖

MOPD 没有省掉领域 RL 的算力；它省掉的是“把所有领域塞进一个联合训练循环”带来的耦合与等待。

Stage 2 可并行

每个领域从同一 SFT checkpoint 出发，独立选 RL recipe、reward、sandbox 与超参；一个领域训练失败或重启，不影响其他教师。

Stage 3 异步

学生 sampler 持续生成；一条序列结束后，训练器向对应教师服务发异步 prefill 请求。教师计算与其他序列的采样重叠，论文称在部署中 teacher “contributed nearly no measurable wall-clock overhead”。

总成本

仍要支付 Stage 1 SFT、Stage 2 每个领域 RL、Stage 3 学生 rollout 与教师 prefill。省的是人工合并与串行等待，不是教师训练本身。

这也解释了为什么论文把“parallelisable pipeline”当作与 dense、on-policy 并列的轴：MOPD 的结构把能力生产（Stage 2）与能力整合（Stage 3）拆开，领域团队可以各自迭代，最后只在一个蒸馏阶段汇合。代价是系统更复杂：需要路由、教师服务、异步 prefill 和跨服务传输 top-k logits；论文在单篇里没有给这些组件的吞吐或故障率数据。

05

同一 SFT 起点分叉出教师，最后在策略空间汇合

流程图上最重要的两条线：Stage 2 的教师并行分叉，以及 Stage 3 学生 rollout 与教师打分的汇合。

为什么强调 same-origin

教师不是从外部拿来的强模型，而是从同一个 SFT checkpoint 出发做领域 RL 得到的。因此教师与学生的初始策略分布接近，Stage 3 开始时的 KL 就低，训练更平滑。论文用一组替换实验验证这一点：把 Math 教师换成 Qwen3-235B-A22B（数学更强、但分布不同），其他教师与超参不变。

同源教师

初始 KL ≈ 0.04

PG 与 Top-K 两条训练曲线都平滑，Math 准确率稳步上升，策略熵稳定在 0.30 左右（Figure 3）。论文的默认 MOPD 用的就是这种教师。

外部强教师

初始 KL ≈ 0.19

论文称约高 5 倍（0.19 / 0.04 = 4.75，原文写约 5×）。PG 形式下 Math 准确率逐步退化，熵从 0.30 收缩到 0.21；Top-K 形式在约第 18 步出现灾难性发散，KL 与熵剧烈震荡（Figure 3）。

这组结果的含义不是“强教师没用”，而是：在 on-policy 蒸馏里，教师与学生的分布对齐会直接影响优化稳定性。论文没有把 cross-origin 退化拆成“梯度方向错”还是“方差爆炸”两个机制；它给出的解释是学生在教师低概率区域收到的主要是惩罚性梯度，策略收窄到单一模式。Top-K 的发散则是实验观察，论文没有给收敛性证明。

四个观察

Mix-RL 最平衡，但仍差 5.55 点

Mix-RL 的领域间极差是 0.064，是四个基线里最小的；但它的整体归一化分数 0.8818，仍比 MOPD 的 0.9373 低 5.55 个百分点。论文把它归因于跨领域信号干扰。

Cascade 的 IF 很强，Math 掉了

Cascade 的 IF 归一化分数 0.979，接近教师；Math 只有 0.567。Figure 2 显示 Math 准确率在后续 SWE 阶段下降，说明串行训练确实会让先训练的能力回退。

Off-Policy 的 IF 超过教师，SWE 不足

Off-Policy 的 IF 归一化分数 1.009，略高于教师；SWE 只有 0.649，论文说离线模仿教师轨迹在不同任务类型上迁移不均。

MOPD 的分差最小

MOPD 三个领域是 0.910 / 0.954 / 0.948，极差 0.044；Cascade 是 0.412，Off-Policy 是 0.359。两个极差按未舍入的三领域归一化值计算：Cascade 0.978954 − 0.567422 = 0.411532，记 0.412；Off-Policy 1.008503 − 0.649351 = 0.359153，记 0.359（若用页面显示的三位小数相减，Off-Policy 会得到 0.360）。论文据此说 MOPD 的 profile 最均匀，但没有说它是唯一均匀的方法。

样本效率：到教师平台所需的领域样本

Figure 2 的横轴是每个领域累计训练的样本数。论文报告 MOPD 在 IF 上约 25K 样本、SWE 上约 30K 样本就到达教师水平；Mix-RL 则要在每个领域用满 150–180K 样本才接近同一水平。按这组数字算，IF 约 6.0–7.2 倍、SWE 约 5.0–6.0 倍 推断（由 §4.2 的 25K/30K 与 150–180K 相除）。这里的“省样本”指 Stage 3 蒸馏达到平台所需的数据，不是总训练算力。

07

它不是“拿最强教师就能蒸馏”：同源、算力、任务范围三道边界

MOPD 的失败条件比成功条件更值得看：教师必须同源，Stage 2 的算力省不掉，任务仍以可验证领域为主。

教师必须同源

外部强教师会让训练不稳

Table 4 的 Qwen3-235B-A22B 实验说明，教师绝对能力更强并不保证学生更好。跨分布教师的初始 KL 高约 5 倍，PG 退化、Top-K 发散。要用外部教师，可能需要先做分布对齐或重新训练教师，论文没有给这套流程。

总成本没有消失

省的是耦合，不是教师 RL

Stage 2 仍要为每个领域跑完整 RL；Stage 3 还要学生 rollout 与教师 prefill。论文没有给 GPU 型号、卡数、总 GPU 小时，也没有把各基线对齐到相同算力，因此不能把 0.9373 当成“同算力下必然更好”。

任务范围也有限。主实验是 Math（AIME25/26）、IF（IFBench/IFEval）与 SWE（SWE-bench Verified）三个领域；MiMo-V2-Flash 扩展到 Code、Tool Use 等，但它是工业模型，论文没有公开 309B 的完整超参、数据配比与训练细节。开放域生成、多模态、长程 Agent 任务没有验证。

方法上，MOPD 仍以 reverse KL 模仿教师，教师的错误会以逐 token 监督的形式传给学生（推断，由 Eq. 1 的逐 token KL 目标推出）；论文没有给教师质量的上界分析，也没有讨论教师在某些 token 上过度自信时的校正。多轮迭代只验证了一轮，且 SWE 没有重新训练教师，不能据此推断所有领域都能持续提升。

最后，路由假设每个 prompt 的领域是已知的。论文的数据集按领域组织，所以路由是明确的；如果遇到跨领域 prompt、混合任务或领域边界模糊的输入，需要额外的分类器或路由策略，论文没有评估这部分误差。
