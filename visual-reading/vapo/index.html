VAPO：价值模型不是训不起来，是没被系统地对齐

无价值模型的 GRPO / DAPO 靠「组内奖励均值」当基线，稳定但只能做轨迹级信用分配。论文认为价值模型能给出逐 token、更低方差的优势估计——前提是先修好三件事： 价值初始化偏差、固定 λ 的 GAE、稀疏的 0/1 奖励。VAPO 用七项改动逐一应对，在 Qwen2.5-32B 上把 AIME 2024 的 avg@32 从 Vanilla PPO 的 5 分推到 60 分（Table 1）。

TL;DR · 30 秒抓住核心

价值模型的三个病。（1）价值网络常用奖励模型初始化，奖励模型只在 <EOS> 上打分，对不完整前缀给低分，于是每个位置的初值都系统性偏高；（2）λ=0.95 时，终止奖励回传到第 t 个 token 的系数是 0.95T−t，长序列里趋近 0，价值更新几乎全靠有偏的 bootstrapping；（3）验证器只给 0/1，长 CoT 让正样本更稀缺。

对症下药。前两病用 VC-PPO 的 Value-Pretraining（固定策略采样、用 Monte-Carlo return 预训价值网络到 explained variance 够高）和 Decoupled-GAE（价值更新 λ=1.0，策略更新另设 λ）。第三病对应 Clip-Higher、正样本 LM 损失、Group-Sampling（后者从 GRPO 借用）。

最值得记住的一点是 Length-Adaptive GAE：把 GAE 系数的总和固定为 αl，解出 λpolicy = 1 − 1/(αl)，α=0.05。序列越长 λ 越接近 1，终止奖励的权重不再随长度指数衰减。消融显示这一项单独贡献 60 − 45 = 15 分（绝对点差）。

01

长 CoT 的 RL，难在「每一步」该拿多少功劳

读完这节你应该知道：为什么在只有终局 0/1 奖励时，逐 token 的价值估计会整体失真。

论文把语言生成写成 token 级 MDP（§2.1）：状态是「prompt + 已生成的全部 token」，动作是下一个 token，轨迹在 <EOS> 处结束。奖励只在终止 token 给出：

"In traditional RLHF and most tasks related to LLMs, the reward is sparse and is only assigned at the terminal action ω, that is, the end-of-sentence token <eos>."§2.2

优势估计 Ât = Σl (γλ)l δt+l（Eq. 3）里的 δt = R(st, at) + γV(st+1) − V(st)。除了终点，每一步 R(st, at) 都是 0，所以每一步的优势几乎完全来自 V。价值网络稍微偏一点，整个信号就偏；价值网络偏得越久，GAE 的递归就把误差累得越大。

再加上推理模型的回复长度本身极不稳定，长、短序列对偏差–方差权衡的要求不同。论文的 §3 把这三个问题拆成三节，§4 对应用三组改动分别处理——这一一对应也是后面读方法时的线索。

02

两路主流方案：一路绕开价值网络，一路硬训价值网络

读完这节你应该知道：VAPO 站在哪条路上、批判的对象是谁、以及它借了哪些前人的零件。

无价值模型

GRPO / DAPO

做法：用一组回复的奖励均值当基线，把轨迹级优势直接当成每个 token 的优势；不需要价值网络，省掉它的算力开销。

论文的评价：「value-model-free methods deliver an accurate and stable baseline」（§1）。但也指出它们难以做到精确的逐步信用分配（§1 引 [21][30]）。

论文观点：价值模型若能训好，能提供逐 token 的信用分配和更低方差的估计，性能上限更高（§1）。

基于价值模型

PPO / VC-PPO / ORZ

Vanilla PPO：价值网络用奖励模型初始化，样本级损失，λ=0.95。论文 Table 1 中只有 5 分，训练后期回复长度急剧收缩、直接作答。

VC-PPO：论文说「Value-Pretraining ... This phenomenon is first identified and addressed in VC-PPO」（§4.1）。对 Decoupled-GAE，§4.1 写 VAPO 只「adopt the core idea of decoupling GAE computation」：价值更新的 λ=1.0 与策略更新的「更小 λ」这条思路来自 VC-PPO，而 VC-PPO 的具体取值 λcritic=1.0、λpolicy=0.95 是 VC-PPO 自己的设定（「In VC-PPO, this is achieved by employing ... λcritic = 1.0 and λpolicy = 0.95」）；VAPO 的策略 λ 改用 Eq. 5 按长度自适应。

ORZ：同样用价值模型，但以 Monte-Carlo 估计代替 GAE；论文称它「could just achieves a comparable performance to value-model-free method」（§6）。

所以 VAPO 的定位不是另起炉灶。§1 写它「draws inspiration from prior research works such as VC-PPO [30] and DAPO [29]」；七项改动里，Value-Pretraining 与 Decoupled-GAE 来自 VC-PPO，Clip-Higher 与 Token-Level Loss 来自 DAPO，正样本损失是 SIL 式的 self-imitation learning，Group-Sampling 来自 GRPO（§1 贡献第 3 条）。论文明说的新增点是 Length-Adaptive GAE（§1 贡献第 2 条）；其余各项按 §1 贡献第 3 条归为对前人技术的系统整合，并用消融验证必要性。

论文对自身定位的原句两处措辞不同，并列引用

§1 贡献第 1 条：「VAPO, the first value-model-based RL training framework to outperform value-model-free methods on long COT tasks significantly.」

§7 结论：「By introducing seven novel techniques atop PPO ...」（未说明哪几项为 VAPO 新提出）。

对比 §1 贡献第 3 条：「We systematically integrate techniques from prior work ...」并列出了 VC-PPO / DAPO / SIL / GRPO 的来源。本页不判断哪几项属于「novel」：§1 贡献第 2 条点名 Length-Adaptive GAE，贡献第 3 条把其余归为前人技术的整合，两处没有逐项对照。

Value-Pretraining：先把价值网络拉到「看得懂回报」

§4.1 给了三步：用固定策略（例如 πsft）持续采样；用 Monte-Carlo return 更新价值网络，直到 value loss 与 explained variance 等指标足够低；保存 checkpoint 供后续实验加载。§5.1 的参数表写的是「a value network warmup for 50 steps based on the reward model (RM) before initiating policy training」。论文未写明：这 50 步预训练用的是哪一批采样、value loss / explained variance 的具体阈值是多少。本页不给推测值。

Decoupled-GAE：价值的 λ=1，策略的 λ 另算

价值更新目标用 λ=1.0，论文称这带来「an unbiased gradient-descent optimization」（§4.1）；策略更新则用更小的 λ 以约束计算与时间。§5.2 解释移除它的后果：「reward signals to exponentially decay during backpropagation」。注意原文的 27 点下降是相对完整版 60 的绝对点差（60 − 33）。

Length-Adaptive GAE：让系数总和跟着长度走

固定 λ=0.95 时，长序列（l>100）里 TD 误差上奖励对应的系数是 0.95100 ≈ 0.006（§4.2）。论文改为令系数之和正比于序列长度 l：

Σt≥0 λpolicyt ≈ 1 / (1 − λpolicy) = α l   ⟹   λpolicy = 1 − 1 / (α l)
Eq. 4（左）与 Eq. 5（右），§4.2；α 控制整体偏差–方差权衡，§5.1 取 α = 0.05

直观地说：序列越长，λ 越接近 1，单步 TD 误差的贡献衰减得越慢；而所有系数加起来始终是 αl，长序列里有更多步、每一步分摊到更多项。下面的交互可以按 Eq. 5 直接算 λ。

Token-Level Loss：每个 token 等权

原损失（Eq. 6）先在序列内对 token 求平均、再对 batch 求平均，长序列的每个 token 权重被稀释；Eq. 7 改为在 batch 内所有 token 上统一平均。论文在 §5.2 称「Token-level loss implicitly increased the weight of long responses, contributing to a 7-point gain」。

Clip-Higher：给低概率 token 留上行空间

Eq. 8 把裁剪区间拆成 εlow 与 εhigh，§5.1 取 εhigh=0.28、εlow=0.2。论文的理由是「leave more room for the increase of low-probability tokens」，而 εlow 保持较小，因为「increasing it will suppress the probability of these tokens to 0」。

Positive Example LM Loss：正确轨迹加一条 NLL

对采样到的正确答案集合 T 追加 NLL 损失（Eq. 9），总目标为 L = LPPO + μ · LNLL（Eq. 10），§5.1 取 μ=0.1。§1 把它的来源标为 SIL [14]。

Group-Sampling：少样本、多重复

同样的计算预算下，论文对比「尽量多 prompt、每个采样一次」与「少 prompt、多次重复采样」，称后者「yields marginally better performance」（§4.3），消融中对应 60 − 55 = 5 点（绝对）。

按我的整理

三处需要并列阅读的地方

  • 60 还是 60.4：§5.2 写「achieves a new SOTA score of 60.4 within just 5,000 steps」；Table 1 的 VAPO 行写 60；§1 写「from vanilla PPO a score of 5 to 60」，同段称「surpassing ... DAPO [29] by 10 points」（按 Table 1 为 60 − 50 = 10，绝对；按 60.4 则为 10.4）。
  • 预训练 50 步：§4.1 说训到「value loss and explained variance ... attain sufficiently low values」再保存，§5.1 只给了「50 steps」。两处描述的终止条件都在 Eq. 4–5 一节之外的 §4.1，本页不判断哪个是实际采用的早停标准。
