EMPG：用每一步的「不确定性」，把稀疏奖励的信用分配重新校准一遍

长时序 Agent 只有最终成败一个信号，中间哪一步关键，策略梯度并不知道。论文先证明了一个常被忽略的耦合：策略梯度的期望范数随熵单调变化——自信步骤梯度小、不确定步骤梯度大而噪声也大。 EMPG 把每一步的平均 token 熵做成乘在优势上的缩放系数，再给「让下一步更清晰」的动作加一项奖励，以即插即用的方式叠在 GRPO / DAPO 之上。

Jiawei Wang, Jiacai Liu, Yuqian Fu 等 · ByteDance arXiv 2509.09265 ↗ 项目页 ↗
TL;DR · 30 秒抓住核心

问题不是「没有奖励」，而是奖励的落点错了。论文把信用分配视为信号失真：所有步骤共享轨迹级优势 A，而每步的梯度范数由自身的熵决定——置信度天然地在调节更新幅度，却没被任何人利用。

自校准梯度缩放：把步级熵做批次 min-max 归一化，用 g(H)=exp(−k·H_norm)/mean 乘在 A 上，批次均值恰好为 1——它只做重分配、不整体放大。高置信步骤得到放大，高熵探索步骤被压低。

未来清晰度奖励：再加一项 ζ·exp(−k′·H_norm(t+1))，奖励「让下一步更确定」的动作，给探索指了方向，而不是盲目乱走。

作为纯 advantage 调制模块，它叠在 GRPO 与 DAPO 之上，三种任务、三档模型规模全部涨点，且 OOD 涨幅大于 ID 涨幅——说明学到的是应对不确定性的能力，而非拟合训练分布。

01

梯度的大小，其实早就被熵偷偷决定了

读完这节你应该明白：为什么「把所有步骤一视同仁地乘同一个优势」会同时导致学得慢和训得抖。

论文把长时序任务建模成标准 RL：一条轨迹 τ=(s₀,a₀,r₀,…,s_T,a_T,r_T)，非终止步奖励全为 0，无折扣（γ=1），所以回报完全由最终成败决定：R(τ)=r_T∈{0,1}。一个 step 对应一次完整的「先思考、再行动」（ReAct 式）。

在这种设置下，难的不只是奖励稀疏，还有 credit assignment（信用分配）。策略梯度写成：

∇θJ(πθ) = 𝔼τ~πθ[ Σt=0T A(st,at) ∇θ log πθ(at|st) ]
Eq. 2 · 所有步骤都乘同一个 A —— 论文称之为 coarse, trajectory-level 的信用分配

但即使 A 完全相同，每一步对参数的实际推动力也不同。论文的 Proposition 1 给出原因：对 logits 做 softmax 的策略，score function 的期望平方范数直接由策略的 Rényi-2 熵 H₂(π) 决定：

𝔼a~πθ[ ‖∇zθ log πθ(a|s)‖2 ] = 1 − exp(−H2(π))
Eq. 5 · 附录 A 的证明转化为 1 − Σj πj2（碰撞概率），而 Σπj2 = exp(−H₂)

熵越低，右边的值越小。直觉是：策略越自信，正确动作就脱离了其它候选，log-softmax 的梯度就越小。于是出现两难：

第一难

自信且正确，反而学得慢

这类步骤最该被强化，但它的梯度天然就小——同样的 A，推动参数的力度不够，收敛被拖慢。

第二难

不确定的探索，反而很吵

高熵步骤梯度大，一旦轨迹失败，大幅负更新会把有益的探索一起打掉，训练剧烈波动。论文称之为 entropy-gradient coupling。

所以目标不是「把熵压小」——那会诱发 hallucinated confidence（自信地错）。目标是按每一步的不确定性，重新校准学习信号。

02

前人两条路都在「从外部造奖励」，都没看模型内部

论文把相关工作对照成两路：造稠密奖励 vs 组内相对优势——各自都把整条轨迹当成一个整体。

路线 A

造稠密奖励

做法：reward shaping、基于新颖性的内在动机、逆向强化学习，或 Process Reward Model（PRM）逐步打分。

卡在哪：计算代价大、不适配庞大的状态-动作空间；PRM 要大量人工标注、合成数据训练易带噪、在 OOD 上泛化差。交互式任务里「哪一步正确」本身就依上下文而定，步骤标签难以定义。

路线 B

组内相对优势（GRPO / DAPO）

做法：GRPO 对同一 query 采样 M 条响应，用 Z-score 形式的组内相对优势 A=(r−mean)/(std+ε)；DAPO 再加动态采样与解耦裁剪。

卡在哪：它们为单轮生成设计，把整条动作序列当成一个整体块（monolithic block），只给出轨迹级信用分配，定位不到长序列里真正关键的那一步；同时忽略了每一步可用的内在信号。

还有第三种更近的做法：用熵来调制优势。SEED-GRPO 用语义熵给高熵响应降权，Cheng 等人用 token 级熵塑造优势，EDGE-GRPO 在单轮数学推理上放大自信正确、衰减错误与不确定的更新。但它们都停留在token 级或响应级的单轮生成；论文认为，如何把 Agent 的内在不确定性用于多步长时序的信用分配，仍然欠探索。

抓手

一个关键观察：token 级的规律在 step 级不成立

近期有工作发现「RL 主要更新高熵 token」。论文在 ALFWorld 上分析超过 9,000 个步骤，按初始熵的分位区间统计 RL 后的平均熵变化（Figure 3）：即便初始熵很低的步骤（例如 15%–20% 分位）也发生了可观的熵变化。说明一个自信的步骤同样可能需要大幅更新，调制必须在整个置信度谱上生效，而不能只盯高熵区域。

03

两个反方向的修正：一个管幅度，一个管方向

整篇方法就四行公式：步级熵、归一化、自校准缩放 g(H)、未来清晰度奖励 f(H)。

第一步：把一步的不确定性量化成一个数

一个 step 由 token {w₁,…,w_m} 组成，取其中每个 token 的熵的平均：

Ht = − (1/m) Σj=1m Σv∈V p(v|w<j) log p(v|w<j)
Eq. 7 · H 越低 = 这一步越自信；论文选它是因为它与 Proposition 1 的梯度动力学直接挂钩，且计算便宜

第二步：自校准的梯度缩放 g(H)

先做批内 min-max 归一化，再取指数并按批内均值归一：

Hnorm,t = (Ht − min(H)) / (max(H) − min(H) + ε)
g(Ht) = exp(−k · Hnorm,t) / meanbatch[ exp(−k · Hnorm) ]
Eq. 12 + Eq. 10 · 分母保证批内 Σg = 1 的约束（Eq. 9），即只「重分配」学习信号，不整体放大

H_norm 落在 [0,1]，exp(−k·H_norm) 是递减正数，再除以均值，于是：低于批次平均熵的步骤得 g>1（放大），高于平均的得 g<1（衰减）。论文给的定性规则：

  • 自信 + 正确（A>0, 低熵）：g 大，正向更新被放大，加快收敛。
  • 自信 + 错误（A<0, 低熵）：g 大，负向更新被放大——强纠正「幻觉式自信」。
  • 不确定（A 任意, 高熵）：g 小，噪声更新被压低，保护探索、稳定训练。

第三步：未来清晰度奖励 f(H)

f(Ht+1) = exp(−k′ · Hnorm,t+1)
Eq. 11 · 下一步越清晰（H 越小），奖励越大；它只加正项，是内在动机

把它理解成奖励「通向更可预测未来」的动作，对应一个逐步目标 mina_t H(πθ(st+1))（Eq. 6），论文用 information gain / empowerment 的观点解释它。两部分合起来就是调制后的优势：

Amod(i,t) = A(i) · g(Ht) + ζ · f(Ht+1)
Eq. 8 · 乘性项（自校准缩放，管幅度）+ 加性项（未来清晰度，管方向）

论文附录 B 进一步把整个更新写成复合目标的梯度：JEMPG = Jextrinsic + Jintrinsic（Eq. 16）。外推项是把原目标换成「状态相关的加权测度」，内推项正是 clarity reward 的累积期望——所以 GEMPG = Σ [A·g(H_t) + ζ·f(H_{t+1})] ∇log π（Eq. 24）不是拼凑，而是某个目标的真实梯度。

04

它的代价几乎为零：不改采样，只改优势

不需要 value model、不需要额外 rollout、不需要外部标注——只在优势上多算两次 exp。

EMPG 被实现成一个 advantage modulation module，直接叠在 GRPO 或 DAPO 之上：采样、裁剪、KL 惩罚统统不动，只把 A(i) 换成 A_final(i,t)。Algorithm 1 把它拆成 6 步，每轮训练内完成：

  • 采样一批轨迹，算出每条轨迹的结果优势 A(i)。
  • 收集批次内所有 step 的 token 熵均值 {H_t}（熵在 rollout 时本来就有，取均值即可）。
  • 归一化：批内 min-max 得 H_norm，按 Eq. 10 得 g(H_t)。作者特意用了无状态的 min-max，而不是用历史统计——这样它会自动跟随策略自信度的变化。
  • 调制：对每个 step 算 f(H_{t+1})，组装 A_mod。
  • 零均值归一：把整批 A_mod 去均值得到 A_final（方差缩减，标准做法）。
  • 更新：用 A_final 做策略梯度。

超参数只有三个：k（缩放锐度）、k′（奖励锐度）、ζ（奖励权重）。论文两组实验都固定 k=k′=1.0，ζ 在 WebShop / ALFWorld 取 0.05、Deep Search 取 0.1。由于 g 的批内均值为 1，缩放本身不会整体改变学习率，理论上与原有优势归一化的配合更稳。

无 value model

延续 value-free 路线

与 GRPO / DAPO 一样直接由组内采样估计优势，省去与策略同规模的 critic 及其内存开销。

便宜

熵是现成的副产品

rollout 时每个 token 的熵已算出，步级 H 只是对 action 段取均值，调制只是两次 exp 与一次批内均值。

通用

换底座即插即用

与具体算法解耦：论文在 GRPO 与 DAPO 两种底座、三种任务上验证，收益不依赖某个特定 backbone。

实验设置速览WebShop / ALFWorld 与 Deep Search 是两套配置

WebShop、ALFWorld 在 Verl-Agent（veRL 上的 Agent 扩展）中训练。原实验在 H200 上跑，作者因资源限制改用 A100：1.5B 用 4×A100，7B 用 8×A100，所有 baseline 在相同硬件、种子、设置下重训。学习率 1e-6、批大小 16、训练 150 步、rollout 组大小 8、温度 1.0；ALFWorld 最多 50 个动作，WebShop 最多 15 个。WebShop / ALFWorld 的实现基于 GiGPO 公开代码库。

Deep Search 在 ByteDance 内部的 RL 框架上训练，模型为 Qwen2.5-32B-Instruct，配 Bing Search 与网页阅读工具；训练集是从 WebWalker、HotpotQA、2WikiMultiHopQA、NaturalQuestions、TriviaQA 中过滤出的 17k 条。批大小 64、训练 220 步、rollout 组大小 16、32×A100，KL 系数 0.001、熵系数 0。

05

一次训练迭代里，信号被改写了两遍

论文 Figure 1 左侧的机制示意，重绘成数据流：每个 step 从「共享 A」变成「A·g + ζ·f」。

这套流程不增加 rollout 次数，也不需要额外的模型。它在计算上唯一的额外成本是批内再跑一遍熵的归一化与两次指数运算——相较于 32B 模型的采样与反传，可以忽略。

训练稳定性

KL Loss 不再后期失控（Figure 2）

在线 RL 微调常见 policy collapse：后期策略发散、性能断崖。论文追踪训练中的 KL Loss：DAPO 基线在约 240 步后 KL 开始剧烈抖动，而 EMPG 加持的版本全程保持低而平稳。为公平比较，基线与 EMPG 都在 220 步取 checkpoint 评估——作者特别指出，EMPG 若继续训练还能再涨。

学习曲线方面（Figure D.1，7B 模型在 WebShop / ALFWorld 验证集上），基线普遍早早进入平台期、成功率停滞；EMPG 版本则持续突破这一平台，最终收敛到明显更高的成功率。论文据此认为，它不只是加速收敛，而是让策略跳出基线陷入的局部最优。

07

它是「加权器」，不是新的不确定性理论

以下几条里，边界一、边界三由论文自己的数据或设置可以直接读出，其余几条是本页的推论。

边界一

强底座上增益变小

7B DAPO 在 ALFWorld 上已经 90.0，EMPG 只能加到 91.6（+1.6）；1.5B GRPO 上则是 +8.1。当底座的信用分配本身已足够好、轨迹中的失配步骤很少时，可校准的空间也小。

边界二（推论）

熵只是不确定性的代理

作者未讨论熵代理的局限，仅将 MC dropout/集成方差列为 future work（§4.1）。§4.1 中作者把平均 token 熵设为默认选择，理由是它与 Proposition 1 的理论联系最直接。至于「模型可能以极低熵自信地生成错误内容」，这是 §1 引用文献 [45] 时的背景陈述，不是作者对本身工作的自评。由此引出的是本页推论：EMPG 会放大对低熵错误步骤的惩罚，但无法消除熵与语义真实性之间的鸿沟。

边界三

只在文本 Agent 上验证

实验覆盖 WebShop、ALFWorld、Deep Search 三种文本交互环境，最大到 32B。具身 AI、多智能体协作被列为未来工作，连续动作、多模态输入下的表现尚无数据。

边界四（推论）

「往清晰走」可能压掉长期探索

Future Clarity Bonus 奖励进入更确定的状态。短期看它把探索导向有意义的路径；但一个暂时高熵、长期更优的路径也可能被系统性低估。论文没有对这一点做专门实验，只有 Deep Search 上 Bamboogle 一栏 OOD 分数（EMPG 84.8，仅 Gradient Scaling 时 86.4）暗示加性奖励并非每个子集都最优。

边界五（推论）

调制的方向取决于原始优势符号

g 只放大或缩小 A 的绝对值：当 A>0 时放大利于快速学习；当 A<0 时放大意味着更重的惩罚。若底层算法给出的优势本身有偏（例如组内全成功或全失败时 std 为 0，GRPO 的 Z-score 退化），EMPG 会把这个偏差同样放大。论文用 DAPO 的过滤采样应对此类批次，但 EMPG 自身不处理。

一句话：EMPG 的贡献是把「熵-梯度耦合」这条已有事实变成一个可插拔的加权器，而不是提供更精确的不确定性度量。它的收益大小，取决于底座留下多少可校准的失配。
