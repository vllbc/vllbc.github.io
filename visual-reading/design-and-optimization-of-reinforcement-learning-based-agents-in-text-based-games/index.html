01

文本游戏把“读懂”与“决策”绑在同一个循环里

读完这节应该知道：为什么文本游戏对 agent 难，以及论文把难点归到哪里。

文本游戏只用自然语言交互：玩家输入文本命令，环境用文本描述场景与后果（§2.1）。这带来两个同时发生的问题。第一，状态空间由语言构成，任何细微的措辞变化都可能意味着新状态；论文在 §2.2 把它描述为 “high in dimensionality, high in level, and requiring high reasoning and decision making capability”。第二，agent 不只要解析当前句子，还要识别目标、记住线索、规划多步动作（§2.1）。

论文的判断是：这类任务同时考验语言理解与序贯决策，因此适合把深度学习（负责表示与解析）与强化学习（负责试错与策略优化）接起来（§1、§2.2）。第 03 节会看到，这个“接起来”在论文里是概念上的分工，不是一条可执行的训练管线。推断（依据：§3–§4 只罗列组件名词，未给配置取值与实现细节；详见第 04 节）

论文的立论

语言理解与决策不能分开做

§2.1 说，文本游戏的行动自由度高、场景描述复杂；AI 在这里要做的不只是解析命令，还要在动态文本世界里推理并生成策略。§2.2 进一步说，RL 的试错与奖励机制可以在这种高维状态空间里学习行为模式。两句合起来就是论文的出发点：用一个 RL agent 同时承担解析与决策。

02

规则与模板 agent 卡在泛化，值函数方法卡在高维

论文对前人的描述只有两类，且没有点名任何具体系统或论文。

第一类是规则或模板 agent。§2.3 说它们“fail to provide generalization and cannot cope with dynamic and complex circumstances”，面对大量游戏文本时不做全局推理，动作次优，也无法适应动态变化的状态空间。这段没有引用具体系统，也没有给出失败案例。

第二类是传统值函数方法。§4.1 在引入 policy gradient 时说，传统方法要建立并更新值函数，在高维状态或复杂任务下“would not converge or be costly in calculation”。论文据此选择直接参数化策略、用梯度上升最大化期望累计回报。这里同样没有给出对比实验或复杂度分析。

论文的判断：无法泛化、不能处理动态复杂场景、不做全局推理、动作次优（§2.3）。

论文未给：具体系统、失败案例、任何对比数字。

论文的判断：高维状态或复杂任务下不收敛，或计算代价高（§4.1）。

论文未给：复杂度分析、收敛条件、对比实验。

03

三段式流水线：解析文本、建世界模型、用策略梯度选动作

这是论文的全部方法。它给每个组件分配了职责，但没有给网络结构、公式或伪代码。

第一步，解析文本并建世界模型（§3.1）。论文用预训练语言模型解析游戏文本，提取隐式环境结构与事实，重建游戏世界状态。原文举例说这类模型“learned via the Transformer structure”擅长捕捉上下文依赖，用来识别目标、任务提示与可交互对象。世界模型再把潜在状态空间与动作后果连起来，预测状态转移。

第二步，用深度学习训练 agent（§3.2）。文本先被编码成状态表示，再送入一个用监督学习或生成模型训练的网络；论文提到用高质量训练集与多任务学习提升泛化。衡量训练效果的 end metrics 有三个：text parsing accuracy、coherency of policy execution、achievement of game objectives。论文没有报告其中任何一个的数值。

第三步，把状态价值转成策略（§3.3、§4.1–§4.2）。策略梯度直接参数化策略，用采样轨迹估计期望累计回报的梯度，再梯度上升更新参数；回报估计可以结合 Monte Carlo 或 temporal difference，advantage function 用来降方差。§4.3 补充了论文认为的优势：直接最大化策略，在高维动作空间里更容易发现好解，不需要高维状态空间的计算。

原文并列

“不用值函数”与“用 advantage”同时出现

§4.1 写 policy gradient “maximise cumulative return in expectation without using value functions”。§4.2 又写 “Advantage functions are used to manage variance”。advantage 通常由值函数估计；论文没有解释这两句如何并存，也没有说明这里的 advantage 用什么估计。页面只并列，不替原文消解。

06

论文声称“超过以往 agent”，但全文没有可核对的数字

读完这节应该知道：哪些句子是原文明确写的，哪些只是主张。这里不替论文补实验，也不把主张当结果。

效果陈述主要分散在摘要与 §3.2、§4.3、§5.1、§5.2、§5.3、§7，全部是定性句。摘要说增强后的 agent“works better in several text-based game experiments and significantly surpasses previous agents on game completion ratio and win rate”；§3.2 说训练指标带来“considerable improvement in text comprehension and decision making”；§4.3 说方法让 agent “better carry out missions at higher ratios”；§5.1 说这些设计“greatly enhance agent performance in a large number of text-based game tasks”；§5.2 说优化 agent 在 task completion 上更高效准确、在 win ratio 上“obviously surpass regular agents”；§5.3 说它在不同实验里拿到更好的 winning ratio 与 completion ratio；§7 再次说结果“has high completion ratios … and win ratios over existing agents to a large extent”。

这些句子没有伴随表、图、实验数值、方差、数据集名或基线名。§5.2 提到 “multiple rounds of game experiments”，但没有给轮数；§5.3 提到 “different experiments”，但没有给实验数量。全文也没有说明 completion ratio 与 win ratio 的分母、判定规则或统计方法。

07

它能当框架读，不能当选型证据

论文自己承认的局限，加上页面核对到的证据缺口。

§7 自述了两个 open questions：training effectiveness，以及对新场景的 adaptability；并说在更真实的文本游戏场景中设计与优化 agent 仍是“a fundamental and hard problem that must be investigated more profoundly”。这是论文作者自己的边界，不是页面的评价。

页面的核对结果是：全文 6 页，没有实验表或实验图，没有数据集名、游戏环境名、基线名、实验数值、方差或显著性检验，没有 GPU 型号、卡数或训练时长，也没有代码仓库链接。参考文献 5 条。§5.2 的 various 与 multiple rounds、§5.3 的 different experiments 都没有给出具体数量；摘要的 several 与 §5.1 的 a large number 同样如此。

缺口 1

没有实验表

completion ratio 与 win ratio 只有定性句，没有实验数值、分母或判定规则。

缺口 2

没有基线

“regular agents”“previous agents”“traditional agents”都没有定义，也没有点名具体系统。

缺口 3

没有实现

没有模型名、网络结构、超参、数据规模、算力或代码；按正文无法复现。

因此这篇论文适合用来理解“一个文本游戏 agent 可以拆成哪些模块”，不适合用来判断“哪条路线更强”。需要可复现基线、效果排序、统计显著性检验或工程选型依据时，这篇不能作为证据；它没有提供这些。

论文对“策略梯度不用值函数”与“用 advantage function”的并列表述，也提醒读者：推断这里的术语是概念层面的，页面无法判断实现层面如何并存。
