Peri-LN：在子层两端各放一个归一化，让残差干道既通梯度又不积方差

Post-LN 把 LN 压在残差相加之后，方差稳了，梯度却要一层层穿过 LN；Pre-LN 把 LN 挪到模块输入，梯度通了，模块输出却直接堆进残差干道。 这篇论文把 Gemma、OLMo 等模型里已经出现的第三种做法命名为 Peri-LN：模块输入和输出都归一化。作者用方差递推和梯度上界解释它为什么有效，并在 400M / 1.5B / 3.2B、30B token、5 个种子上与 Post-LN、Pre-LN 对比。

Jeonghoon Kim 等 · NAVER Cloud · KAIST · NAVER AI Lab arXiv 2502.02732v3 ↗
TL;DR · 30 秒抓住核心

三种放置的差别只在 LN 放在子层的哪个位置，但它决定了残差干道是不是被归一化。Post-LN 把 LN 放在残差相加之后（Figure 2 的 C），主路径被压住，梯度却要穿过 LN。

Pre-LN 只归一化模块输入（A），残差干道没有 LN，梯度路径更直；代价是模块输出不经归一化就加进干道。§3.2 指出，初始化时 Pre-LN 的方差近似随深度线性增长，但训练开始后会指数上升；Figure 1 用 1.5B 模型追踪了这一点。

Peri-LN 在模块输入和输出各放一个 LN（A + B），即 yl = xl + Norm(Module(Norm(xl)))。如果归一化后的模块输出方差近似常数 β0，则 Var(xl+1) ≈ Var(xl) + β0（Eq. 4），方差增长从乘法变成加法。Proposition 3.1 进一步给出：对最后一层 MLP 权重，Pre-LN 的梯度范数正比于 ||h||，而 Peri-LN 的上界带一个阻尼因子 1/||a||（Eq. 8）。

01

Pre-LN 的残差干道越干净，巨量激活越容易一路带到最后一层

先建立问题：LN 放在哪里，决定了模块输出能不能污染残差干道；而这个问题在训练开始后才会暴露。

Transformer 的一个子层可以写成 yl = xl + Module(xl)。残差连接把 xl 原样送到下一层，Module 只负责在主干上加一个增量。LN 放在增量的哪一侧，决定了这个增量在汇入主干前是否被约束。

Post-LN

LN 在残差相加之后

yl = Norm(xl + Module(xl))（Eq. 1）。主路径上的每一步都被归一化，激活不会逐层放大。

代价是反向传播要穿过每一层的 LN。§3.1–3.2 说，深层模型里这会削弱梯度流，可能出现部分梯度消失和更慢的收敛。

Pre-LN

LN 只在模块输入

yl = xl + Module(Norm(xl))（Eq. 2）。残差主路径上没有 LN，梯度可以沿恒等路径直接回传。

代价是 Module(Norm(xl)) 没有归一化就加到 xl 上。模块输出一旦很大，就会沿着残差路径一路保留。

论文把后者和 Sun et al. (2024) 的 massive activations 联系起来：Pre-LN 的残差恒等路径没有归一化，大激活可以从浅层一直传到深层。§3.2 的原句是：

“Pre-LN normalizes xl before the module but leaves the module output unnormalized, allowing hidden-state variance to accumulate exponentially once parameter updates amplify the input.”

关键在“once parameter updates amplify the input”。初始化时，Pre-LN 的方差增长看起来只是随深度线性增加（Kedia et al., 2024，转引）；但论文观察的是训练过程。Figure 1 用 1.5B 模型从初始化追到 6.3B token；§3.2 的文字结论是 Post-LN 的方差大致恒定，Pre-LN 在训练开始后指数上升。Figure 1 的 caption 则笼统写 “the growth in hidden-state variance for both Pre-LN and Post-LN architectures”，措辞比 §3.2 正文更宽泛。Peri-LN 的受控方差是 §3.3 引入 Output-LN 之后讨论的。

这不只是训练曲线好不好看。Figure 11 追踪 3.2B 模型的全局 top-100 绝对激活值：Pre-LN 在 0.5B token 左右就超过 FP16 可表示上限 65,504，而 Peri-LN 一直低于这条线。Appendix K 还提到，V100 不支持 BF16，这类溢出会直接变成数值问题。

本节结论

问题不是“要不要 LN”，而是“LN 要不要碰残差主路径”

Post-LN 让 LN 碰主路径，换来稳定方差，但梯度要穿过它；Pre-LN 让主路径保持干净，换来梯度通路，但模块输出可以不受约束地加进去。两条路都把同一个 trade-off 推到了极端。

02

Post-LN 管住方差但压住梯度，Pre-LN 放开梯度却放开方差

两条主流路线不是谁对谁错，而是把同一个 trade-off 推向了相反的两端；先看清各自卡在哪。

放置位置只有三个：A、B、C

这张表已经说明了三者的结构差异：Post-LN 只有 C，Pre-LN 只有 A，Peri-LN 同时有 A 和 B，但没有 C。也就是说，Peri-LN 保留了 Pre-LN 的干净主路径，同时在模块输出汇入残差之前加了一道约束。

梯度范数的排序，和分数排序并不一致

§4.4 和 Figure 5(a) 报告：在训练稳定的 run 里，final-layer gradient norm 满足 Post-LN > Pre-LN > Peri-LN。但 Table 1 的 benchmark 平均分排序是 Peri-LN > Pre-LN > Post-LN。两组排序方向相反。

论文没有把 final-layer gradient norm 当作排名指标；§5.2 更关心的是梯度在层间是否均匀：Figure 7 显示 Post-LN 在训练后期的低层梯度变小，Pre-LN 在初始化阶段反向传播时梯度变大，而 Peri-LN 在初始化和训练结束时都保持较均匀的逐层分布。推断（依据：§4.4 只报告排序，§5.2 才把“均匀”作为稳定性的解释；两处量的口径不同。）

共同盲区

两者都没有在“模块输出汇入残差之前”做约束

Post-LN 在汇入之后归一化，Pre-LN 在汇入之前只归一化输入。前者让主路径被 LN 覆盖，后者让未归一化的模块输出直接进入主路径。Peri-LN 选的是第三条：在汇入之前，对模块输出本身做归一化。

03

Peri-LN 把模块输出也归一化，方差从指数增长变成每层加一个常数

核心只有一行公式；真正要理解的是它为什么能把方差增长从乘法变成加法，以及梯度上界里的阻尼因子从哪来。

yl = xl + Norm( Module( Norm(xl) ) )
Eq. 3 · 输入侧沿用 Pre-LN 的 Norm(xl)；输出侧新增的 Norm 是 Peri-LN 与 Pre-LN 的关键结构差别

与 Pre-LN 相比，Peri-LN 多了最外层的 Norm；与 Post-LN 相比，这个 Norm 没有放在残差相加之后，所以主路径仍然没有 LN。论文在 §3.3 里把这一步写成 Norm(Module(Norm(xl)))，并指出如果这一项的方差近似常数 β0，就有：

Var(xl+1) ≈ Var(xl) + β0
Eq. 4 · 每层只加一个常数项；结果是线性或次指数增长，而不是 Pre-LN 的指数增长

这就是“外围归一化”的核心：它不改变残差主路径的结构，只在模块输出汇入主路径之前把增量的尺度固定住。主路径仍然可以直通梯度，但不会再被一个未归一化的大增量反复放大。

Proposition 3.1：Pre-LN 的梯度正比于 ||h||，Peri-LN 多了一个分母

论文考虑最后一层 MLP 的权重 W(2)，令 h = ReLU(x̃W(1) + b(1))。两种策略的梯度行为分别是：

Pre-LNx̃ = Norm(x)，a = MLP(x̃)，o = x + a （Eq. 5）
梯度∂L(o)/∂W(2)i,j ∝ ||h|| （Eq. 6）
Peri-LNx̃ = Norm(x)，a = MLP(x̃)，ã = Norm(a)，o = x + ã （Eq. 7）
梯度∂L(o)/∂W(2)i,j ≤ 4γ√D ||h|| / ||a|| （Eq. 8）
Eq. 5–8 · 论文分析的是最后一层 MLP 权重 W(2)；Eq. 8 的阻尼来自对 a 的归一化
Pre-LN

梯度随 ||h|| 放大

模块输入先归一化，输出直接加回残差（Eq. 5）。梯度对最后一层 MLP 权重的范数正比于 ||h||（Eq. 6）。

当 massive activation 让 ||h|| 很大时，梯度范数可以随之爆炸，导致训练不稳定。

Peri-LN

梯度被 ||a|| 阻尼

模块输入和输出都归一化（Eq. 7）。梯度上界带一个 1/||a|| 的阻尼因子（Eq. 8）。

即使 ||h|| 很大，这个比值也能保持有界。论文称之为 self-regularizing gradient。

注意这个上界的范围：它只针对最后一层 MLP 权重 W(2) 的梯度，是局部上界，不是逐层或全局上界。§3.4 与 Appendix C 给了形式化陈述和证明，但论文没有给出端到端的全局收敛证明。这个边界在 §07 还会再提一次。

反直觉一：梯度范数排序和分数排序相反

§4.4 的 Figure 5(a) 说，训练稳定时 final-layer gradient norm 的顺序是 Post-LN > Pre-LN > Peri-LN；Table 1 的分数顺序是 Peri-LN > Pre-LN > Post-LN。论文没有把这个梯度范数当作排名指标，而是在 §5.2 用 Figure 7 强调 Peri-LN 的逐层梯度分布更均匀。推断（依据：§4.4 只报告排序；§5.2 才把“层间均匀”作为稳定性的解释。两处量的口径不同，不能直接合并成“梯度越大越好/越差”。）

反直觉二：强 weight decay 能救 Pre-LN，但补不上差距

Table 7 是 400M 模型的 weight decay sweep。把系数从 0.033 加到 0.33（论文称 tenfold rise，§6.1；0.33 / 0.033 = 10），Pre-LN 的平均分从 49.01 升到 49.51，loss 从 3.03 降到 3；Peri-LN 同期从 50.68 升到 52.13，loss 从 2.93 降到 2.90。强 weight decay 能缓解 Pre-LN 的不稳定，但在同一设置下 Peri-LN 仍然更高。

它解决的是模块输出的方差累积，不是所有训练不稳定

论文的边界写在实验范围里：Decoder-only、最高 3.2B、30B token、主要用 RMSNorm；没有吞吐/推理开销实验。

边界一

残差主路径仍然没有 LN

§7.2 的原句是：“Both Pre-LN and Peri-LN architectures leave the main hidden state path unnormalized, so once large values arise in earlier layers, they persist through to later layers.” Peri-LN 阻止的是模块输出继续把方差加进主路径，不是清除主路径里已经存在的大值。如果问题主要来自残差状态本身，Peri-LN 不一定是足够的解。

边界二

规模和架构范围有限

实验覆盖 400M、1.5B、3.2B 三个 decoder-only 模型，30B token，DCLM-baseline，Llama 3 风格结构，主要用 RMSNorm。论文没有报告 Encoder-Decoder、ViT、多模态、MoE 或超过 3.2B 的实验；这些架构上的行为需要另行验证。

边界三

增益是点差，不是显著性结论

Table 1 报告的是 5 个训练种子的均值与标准差，论文没有做显著性检验，也没有给出置信区间。3.2B 平均分的差值是 +1.87 个百分点（58.56 − 56.69），C4 loss 差值是 0.09（3.20 − 3.11）。这些点差在三个规模上方向一致，但论文没有做显著性检验，不能读成统计显著。

边界四

额外 LN 的开销没有量化

Peri-LN 在每个子层多一次归一化，但论文没有报告吞吐、显存或 FLOPs 的对比。对训练吞吐敏感的场景，需要自己测这部分开销；不能从 Table 1 的分数直接推断“更划算”。推断（依据：全文没有吞吐/显存表格；§7.2 只讨论精度约束。）

边界五

Pre-LN 也能被 weight decay / 初始化稳定

Table 7 和 Table 8 显示，强 weight decay 或 Xavier 初始化都能改善 Pre-LN。Peri-LN 的优势是在这些调参范围内仍然更高，而不是“Pre-LN 无论怎么调都不行”。如果工程上已经有成熟的 Pre-LN 稳定配方，换架构的收益需要和改动成本一起算。

边界六

理论是局部的，不是端到端收敛证明

Proposition 3.1 给的是最后一层 MLP 权重梯度的上界，Appendix C 有形式化陈述与证明；论文没有给出整个训练过程的全局收敛保证。把它当成“Peri-LN 一定不会发散”的依据，会超出原文的范围。

一句话总结：Peri-LN 管的是“模块输出汇入残差之前”的那一步；它把 Pre-LN 的指数方差增长改成线性增长，但没有把残差主路径变成归一化路径，也没有承诺所有规模、所有架构都同样受益。
