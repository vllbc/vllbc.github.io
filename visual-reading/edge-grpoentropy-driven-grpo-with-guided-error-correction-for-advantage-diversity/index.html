EDGE-GRPO：用熵重新加权优势，用参考答案更可能补足全错组

GRPO 的组内优势在“全对”或“全错”时一起变成 0，难样本因此被浪费。EDGE-GRPO 在响应层面按概率对错误回答做引导纠错，让组里更可能出现正例；在信号层面用样本级策略熵缩放优势，让“自信地错”罚得更重、“不自信地对”奖得更轻。Qwen2.5-Math-1.5B 只用 1K 样本，五基准平均从 25.71 升到 48.08。

Xingjian Zhang、Siwei Wen、Wenjun Wu、Lei Huang · 北京航空航天大学 原文 ↗ 代码 ↗
TL;DR · 30 秒抓住核心

GRPO 用组内均值算优势。一个组 8 条回答如果全对或全错，奖励相同，优势全为 0，策略梯度也就为 0；难题上这种组很常见。论文的 Hard-1K 里约 80% 的问题在 8 次采样中全部答错。

EDGE-GRPO 分两层补信号。GEC 对每条错误回答按 0.5 / 0.25 / 0.25 的概率做“提示后重生成 / 提示并给答案 / 直接替换成参考解”，提高组里出现正例的概率；EDA 再把优势除以归一化熵：低熵（自信）放大优势绝对值，高熵（不确定）缩小。

Qwen2.5-Math-1.5B 上，Random-1K 平均 25.71→48.08；7B 上 29.04→49.30。Hard-1K 上 7B 从 47.69 到 53.21。

代价是训练数据要带参考答案：答案注入只需要最终答案，参考解替换才需要参考解；GEC 是“开卷”干预，EDA 的收益依赖组里先有非零优势。论文只验证数学推理，GEC 概率与熵缩放也没有敏感性实验。

01

全对或全错的组，优势一起归零

先看 GRPO 的失效点：优势是组内相对量，组内奖励没有差异时，整组都拿不到梯度。

GRPO 对每个问题采样 G 条回答，用规则 verifier 给每条回答一个奖励，再在组内标准化：

Ai = ( ri − mean({r1, …, rG}) ) / std({r1, …, rG})
Eq. 2：GRPO 的组内优势；ri 通常来自最终答案是否正确。

如果 8 条回答全对，ri 全相等，分子为 0；全错也一样。于是按论文口径记为 Ai = 0（严格说 Eq. 2 为 0/0，实现通常加 epsilon），策略梯度没有信号。论文把这个现象叫 advantage collapse。它不是偶发：在 Hard-1K 里，约 80% 的问题在 8 次采样中全部答错，这些题恰好是模型最需要学习的题。

所以问题不是“奖励太稀疏”这么简单，而是组内没有对照：没有一条比组平均更好的回答，模型无法判断该往哪个方向更新。

02

让模型反思收效有限，按样本看熵又常常错配

已有两条路线：响应层面逼模型反思，信号层面把熵/内部反馈塞进优势。论文先各做了一组量化实验，说明两条都不够。

响应层面

反思回答的准确率反而更低

论文用 15 个反思关键词（check again、recheck、verify again 等）识别回答里是否出现自我反思。多数模型上，含反思的回答准确率明显低于整体；强制模型对错误答案反思，Figure 2 右下报告的准确率多数模型低于 5%。Table 5 按单个触发词统计，多数纠正率低于 10%，0.1 档最高为 11.059%（DeepSeek-R1-Distill-Qwen-7B，Hmm），全表最高为 0.6 档的 12.097%。DeepSeek-R1-Distill 系列相对更高，论文正文称最好的 DeepSeek-R1-Distill-Qwen-7B 也只有约 11%（Table 5、Appendix）。

信号层面

平均熵有方向，样本级却大量错配

论文定义 RCM = (EntropyCorrect − EntropyWrong) / Average Entropy。多数后训练模型的 RCM 为负（Table 3），说明正确回答平均更自信；但逐样本看，约一半错误回答的熵低于平均，近三分之一正确回答的熵高于平均（Figure 3 右）。

Table 3 / Table 5 未全文转录，仅引用定性结论 / 极值（SPEC §1.3-J）。

这两组观察决定了方法：既然模型自己反思很难产生正例，就从外部给答案或参考解；既然熵的 aggregate 方向对但样本级常错，就不能全局鼓励高熵或低熵，而要按每条回答的熵相对组均值来缩放它的优势。

03

GEC 让组里更可能出现正例，EDA 按熵放大或缩小优势

两个模块正交：GEC 改的是“组里有哪些回答”，EDA 改的是“已有优势值怎么缩放”。

响应层面：Guided Error Correction

对每条错误回答，GEC 按固定概率三选一：

P = 0.5

提示后重生成

追加一句反思提示（如 “Wait! Something is wrong here.”），让模型基于提示重新生成，保留自纠机会。

P = 0.25

提示并注入答案

在提示后把最终答案直接拼进这条回答（外部注入，不再生成）；回答的其余部分仍是模型生成，正确目标已写入。

P = 0.25

参考解替换

用外部参考解整体替换这条错误回答；改完之后，组里更可能出现正确样本。

关键点是 GEC 作用在每条错误回答上，而不是只在“整组全错”时启动。这样即使组里已经有一条正确回答，其余错误回答仍可能被纠正，组内正负样本的比例更高，优势更不容易塌成 0。

论文把“每个问题都有最终答案和参考解”列为整体数据条件；逐操作看，直接答案注入只需要最终答案，参考解替换才需要参考解，两者都没有时只能提示后重生成，正例不保证。GEC 是把外部监督注入 RL 组内，不是让模型凭空自纠。论文没有测试低质量或噪声参考解的影响。

信号层面：Entropy-Driven Advantage

对每条回答，先按 token 级策略分布算平均熵 Pi，再除以组内平均熵：

P̂i = Pi / mean({P1, …, PG})
Âi = Ai / P̂i
Eq. 6–7：归一化熵 P̂i 与熵驱动优势 Âi。注意 Eq. 7 是除法，不是乘法。

P̂ < 1 表示这条回答比组内平均更自信；P̂ > 1 表示更不确定。除以 P̂ 后：

  • 正确且自信（A > 0，P̂ < 1）：Â 变大，奖励被放大。
  • 错误但自信（A < 0，P̂ < 1）：Â 更负，惩罚被放大。
  • 正确但不自信（A > 0，P̂ > 1）：Â 变小，奖励被缩小，容忍探索。
  • 错误但不自信（A < 0，P̂ > 1）：Â 的绝对值变小，惩罚被缩小。

注意 EDA 的前提是 Ai 已经非零。整组全对或全错时 Ai 按论文口径记为 0，除以任何 P̂ 仍是 0。GEC 对每条错误回答按概率处理：全错组是主要场景，GEC 能提高组里出现正例的概率；全对组没有错误回答可改，GEC 不执行任何操作，优势仍为 0。

熵驱动优势
Âi = Ai / P̂i = 2.000
正确且自信：放大奖励
手算：四组参数 与滑块输出逐位一致（三位小数）

1）A=1.0，P̂=0.5：Â = 1.0 / 0.5 = 2.000（正确且自信，奖励放大）。

2）A=−1.0，P̂=0.5：Â = −1.0 / 0.5 = −2.000（错误但自信，惩罚放大）。

3）A=1.0，P̂=1.5：Â = 1.0 / 1.5 = 0.667（正确但不自信，奖励缩小）。

4）A=−1.0，P̂=1.5：Â = −1.0 / 1.5 = −0.667（错误但不自信，惩罚缩小）。

滑块范围 A∈[−2,2]、P̂∈[0.5,2.0]；A=0 时输出恒为 0，EDA 无法救回全对/全错组（GEC 只处理错误回答，全对组仍为 0）。

04

1K 样本、8 张 A100、一个 epoch：便宜在数据，不便宜在参考答案

论文没有报告 GPU 小时或 token 成本；能确认的是训练配置、数据规模和 GEC 对数据的额外要求。

训练在 8 张 NVIDIA A100-40G 上进行，每个问题采样 8 条回答，每条最多 1024 token；只训练 1 个 epoch，学习率 1e-6，并去掉了 KL 约束（§Implementation Details、Appendix）。训练集是从 DeepScaleR 过滤后随机抽的 1K 条 DeepScaleR-Random-1K；另外用 Qwen2.5-Math-7B 筛出 8 次采样准确率最低的 1K 条，构成 DeepScaleR-Hard-1K。

数据

1K 条训练样本，1 个 epoch；对比模型使用 5.7K–800K 条（Table 6 的 #Train 列）。

硬件

8×A100-40G；论文没有给出 GPU 小时、训练时长或显存峰值。

GEC 成本

错误回答按概率触发一次重生成、答案注入或参考解替换；论文没有量化额外 token/时间，也没有 GEC 概率的敏感性实验。

GEC 的数据条件值得单独看：直接答案注入只需要最终答案；参考解替换才需要参考解；两者都没有时只能提示后重生成，正例不保证。论文把“每个问题都有最终答案与参考解”列为整体数据前提，这把数据门槛从“答案可验证”提高到“过程可参考”；论文没有测试低质量或噪声参考解。

另一个工程细节是 std 分母。GRPO 的 Eq. 2 在组内奖励全相等时会出现 0/0；论文没有展开实现里的 epsilon 处理，页面不对 0/0 的数值结果做推断。论文的口径是：全同奖励组为 zero advantage；后续 EDA 对 A = 0 也除不出信号。

05

先补组内正例，再重加权，最后才更新

把两个模块放回一次 GRPO 迭代：采样 → 奖励 → GEC → 重新算奖励与优势 → EDA → 策略更新。

Step 1–2

采样与奖励

每个问题采样 8 条回答，规则 verifier 只给最终答案对错。全部同奖时组内分子为 0；其中有错误回答（全错组）时 GEC 会对每条错误回答按概率处理，全对组没有错误回答可改，GEC 不执行任何操作。

Step 3–4

GEC 与重算

对每条错误回答按 0.5/0.25/0.25 触发三种干预；参考解替换会直接写入正确解，提示并注入答案则把最终答案直接拼进回答，两者都让组里更可能出现正例；重生成则给模型一次自纠机会。之后重新算奖励与优势。

Step 5

EDA 缩放

用 Eq. 3–4 算每条回答的平均策略熵，除以组均值得到 P̂，再用 Â = A / P̂ 放大或缩小优势。

Step 6

更新

把 Â 放进 GRPO/PPO 的 clip 目标，更新 actor。论文去掉了 KL 项，理由是训练分布可能显著偏离初始模型。

07

它更可能把“全错组”变成可学信号，但只在有参考答案的数学题上验证

边界有三层：数据要带最终答案或参考解、GEC 是外部监督、评测只覆盖数学推理；此外超参数敏感性没有展开。

数据门槛

答案注入要答案，参考解替换要过程

GEC 的“答案注入”需要最终答案；“参考解替换”才需要参考解；两者都没有时只能提示后重生成，正例不保证。论文在过滤 DeepScaleR 时要求答案位于 \boxed{} 且带 solution；论文没有测试低质量或噪声参考解的影响。

外部监督

GEC 把参考答案放进训练组

这不是模型自己纠错，而是把外部正确解按概率注入。论文的消融显示它有效，但也意味着性能提升部分来自“开卷”信号；GEC 与纯 RL 的贡献比例，论文没有拆分。

评测范围是五个数学基准：AIME24、AMC、MATH500、Minerva、OlympiadBench，共 1560 题；没有代码、科学问答、开放对话或多模态。论文只在五个数学基准上评测，未讨论其他领域，页面不把“数学上有效”扩成“通用有效”。

超参数方面，GEC 的三个概率（0.5/0.25/0.25）与熵缩放都没有敏感性实验；EDA 的熵是 token 级策略熵，论文没有比较语义熵、序列熵等替代信号。训练还去掉了 KL 约束，作者称这是沿用已有工作的做法，但没有给出有无 KL 的对照。

最后一个边界是 EDA 的适用条件：它只能重加权非零优势。全错组可由 GEC 提高出现正例的概率；全对组没有错误回答可改，GEC 不执行任何操作，A 仍为 0，除以 P̂ 仍是 0。页面把这条写成机制约束，而不是“EDA 单独解决优势坍塌”。

EDGE-GRPO: Entropy-Driven GRPO with Guided Error Correction for Advantage Diversity · Xingjian Zhang、Siwei Wen、Wenjun Wu、Lei Huang · 北京航空航天大学
原文：https://arxiv.org/abs/2507.21848v1

笔记：EDGE-GRPO：Entropy-Driven GRPO with Guided Error Correction for Advantage Diversity

笔记勘误（只改页面，不动笔记）：

  • 笔记写「当一组响应被判断为全错时，GEC 会启动」。论文 §Response-level: Guided Error Correction (GEC) 的实际规则是：对每条错误回答按概率三选一，不管同组是否已有正确回答。全错组只是 GEC 最重要的场景，不是触发条件。
  • 笔记写 GEC「保证响应组中至少包含一些高质量的正面样本」。论文措辞也是 ensure（“These three strategies ensure that each group of responses contains positive examples with correct answers”），但按机制应理解为概率性 推断（由 §Response-level: Guided Error Correction (GEC) 的三种操作定义推得）：三种操作按每条错误回答分别以 0.5/0.25/0.25 触发，「提示后重生成」（P=0.5）仍可能继续答错；「提示并注入答案」（P=0.25）把最终答案直接写进回答；「参考解替换」（P=0.25）写入完整参考解。两者都直接引入正确内容，只有「提示后重生成」（P=0.5）仍可能答错，因此 GEC 是提高正例出现的概率，不是绝对保证。
  • 笔记的 Table 1 只摘了 Vanilla GRPO 与 EDGE-GRPO 两个方法（4 行：1.5B 与 7B 各两行），省略了 SFT、+Force-R、+Force-R&EDA。数值本身没错，但读者会看不到「在 Force-R 基础上再加 EDA 在 7B Random 上反而低于 GRPO」这个消融反例；页面补全了 Table 1/2。
  • 笔记写「强制模型反思的成功率极低，大部分低于 5%」。Figure 2 右下是强制反思的准确率，原文称 most models 低于 5%；Table 5 按四个触发词分别统计，多数纠正率低于 10%，0.1 档最高为 11.059%（DeepSeek-R1-Distill-Qwen-7B，Hmm），全表最高为 0.6 档的 12.097%。页面把两个口径分开写。
  • 笔记第 49 行把 GRPO 优势写成 A_i = r_i − mean(...)，漏了 Eq. 2 的 std(...) 分母；论文 Eq. 2 为 (r_i − mean) / std。
