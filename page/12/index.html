论文深度解读

大型语言模型（LLM）驱动的智能体在处理单一、直接的指令时表现出色，但在需要长远规划、多步骤、且环境动态变化的复杂任务中，它们往往会“迷失方向”或“不知变通”。这篇论文精准地指出了当前主流方法的两大困境：一类是高层规划方法（High-level Planning），它们像一个制定了宏伟蓝图但缺乏细节的将军，能够设定清晰的总体目标（例如，分解为几个子任务），但在执行过程中遇到意外情况时（比如环境变化或执行错误）就显得非常僵化，难以适应。另一类是步进式方法（Step-wise Methods），它们像一个只看脚下三步路的士兵，能够根据当前环境灵活地做出反应，但由于缺乏全局视野，很容易陷入局部最优解，导致行为低效、重复，甚至偏离最终目标。

Chain-of-Agents：End-to-End Agent Foundation Models via Multi-Agent Distillation and Agentic RL

vllbc 发布于 2025-08-27 收录于 Agent Reading

一个agent模拟多agent。将多种能力内化到一个agent中。

论文深入解读

在人工智能领域，我们正目睹一个关键的转变：从追求更大、更全能的单一大型语言模型（LLM），转向构建能够协同解决复杂任务的多智能体系统（Multi-Agent Systems, MAS）。例如，让一个“规划智能体”负责拆解任务，一个“研究智能体”负责搜集资料，一个“编码智能体”负责编写代码，它们通过对话协同工作。这种方式在处理深度研究、软件开发等复杂任务时展现了惊人的潜力。然而，正如论文开篇所指出的，现有的多智能体系统存在几个致命缺陷： 1. 计算开销巨大：多个智能体（通常是多个独立的LLM实例）之间的反复通信会消耗海量的计算资源和时间。 2. 泛化能力差：这些系统高度依赖于人工设计的提示（Prompt）和固定的工作流，一旦任务领域或流程发生变化，就需要重新进行繁琐的工程调优。 3. 无法进行数据驱动的学习：最关键的是，系统的核心——那些作为智能体的LLM——通常是预训练好后固定不变的。整个系统无法从解决任务的经验中学习和进化，其性能提升受限于“提示工程”而非“数据驱动”。

经验学习，将成功轨迹和失败轨迹总结成经验，然后作为上下文，还有遇到失败的反馈时，进行反思。

论文深度解读：从“粗放”到“精细”，唤醒大模型的经验智慧

这篇论文的核心思想，是解决当前大模型智能体在复杂任务中“学不精、记不牢、不会反思”的困境。现有智能体，要么依赖成本高昂的在线训练，要么通过简单的记忆机制（例如，存储过去的成功案例）来辅助决策。然而，这些方法往往效率低下，因为它们处理经验的方式是“单粒度的”（single-granularity）。这意味着智能体无法区分哪些是普适的原则性知识，哪些是特定场景下的操作技巧，导致学习到的经验难以泛化，遇到新情况时容易“失忆”或“犯傻”。
