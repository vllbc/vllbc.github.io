Arcee AI Trinity Large

vllbc 发布于 2026-06-06 收录于 LLM LLM Architecture Model

Arcee AI Trinity Large

原文第 20 节。Arcee AI 在 2026-01-27 发布的 400B MoE（13B 激活）。技术报告相当详细。

关键设计

3:1 SWA（介于 Gemma 3 与 Olmo 3 之间）

  • local:global = 3:1（不像 Gemma 3 / Xiaomi 是 5:1，也不像纯 global）
  • 滑动窗口大小 = 4096（与 Olmo 3 类似）

[[NoPE（No Positional Embedding）|NoPE]] in global layers

  • global attention 层用 NoPE（参考 [[SmolLM3]] 的做法）
  • 局部层照常用 RoPE

Gated Attention

  • 不像 Qwen3-Next 是完整 GatedDeltaNet，而是借鉴了 Qwen3-Next 的 attention 门控
  • 在 scaled dot-product 后、output linear projection 前 加 elementwise gating
  • 效果：减少 attention sinks，改善长序列泛化 + 训练稳定性

Gated DeltaNet

vllbc 发布于 2026-06-06 收录于 LLM Attention Linear Attention

Gated DeltaNet

来自 Sebastian Raschka 的 The Big LLM Architecture Comparison。一个线性 attention 变体，是 Qwen3-Next 的核心组件。

一句话

Gated DeltaNet 是 DeltaNet + Mamba 风格 gating 的组合：

  • DeltaNet：用 q / k / v / α / β 维护一个fast-weight memory，按 delta rule 更新（线性 O(n) 缩放）
  • Mamba gating：额外用门控机制控制 memory 写入/读取

→ 本质是”线性 attention 的现代变种”，常被拿来做 3:1 混合中的”线性那 3 层”。
