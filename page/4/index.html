MTP（Multi-Token Prediction）

来自 Sebastian Raschka 的 The Big LLM Architecture Comparison。一个训练阶段的多 token 预测技巧。

一句话

传统 LLM 每个位置只预测下一个 token（next-token prediction）。MTP 在每个位置加几个小的 head（线性层），同时输出 t+1..t+k 的 logits，对所有偏移的 cross-entropy 求和（论文推荐 k=4）。

Partial RoPE

vllbc 发布于 2026-06-06 收录于 LLM 位置编码

Partial RoPE

来自 Sebastian Raschka 的 The Big LLM Architecture Comparison。

一句话

Partial RoPE = 只对每个 head 的部分通道应用 RoPE 旋转，剩下通道不变。

Full RoPE:     [r r r r r r r r]
Partial RoPE:  [r r r r — — — —]
  • 每个 head 的 rotary_dim 通道做旋转
  • 剩余 (head_dim - rotary_dim) 通道保持不变

起源与目的

M1 README 原文：“Rotary Position Embedding (RoPE) applied to half of the attention head dimension with a base frequency of 10,000,000”

QK-Norm

vllbc 发布于 2026-06-06 收录于 LLM 训练稳定性

QK-Norm

来自 Sebastian Raschka 的 The Big LLM Architecture Comparison。

一句话

QK-Norm = 在 attention 模块内，对 q、k 各自加一层 RMSNorm，在 RoPE 之前 应用。起源是 2023 年的 Scaling Vision Transformers 论文。

代码示例

class GroupedQueryAttention(nn.Module):
    def __init__(self, d_in, num_heads, num_kv_groups,
                 head_dim=None, qk_norm=False, dtype=None):
        # ...
        if qk_norm:
            self.q_norm = RMSNorm(head_dim, eps=1e-6)
            self.k_norm = RMSNorm(head_dim, eps=1e-6)
        else:
            self.q_norm = self.k_norm = None

    def forward(self, x, mask, cos, sin):
        b, num_tokens, _ = x.shape
        queries = self.W_query(x)
        keys = self.W_key(x)
        values = self.W_value(x)
        # ...
        if self.q_norm:
            queries = self.q_norm(queries)
        if self.k_norm:
            keys = self.k_norm(keys)
        # apply RoPE
        queries = apply_rope(queries, cos, sin)
        keys = apply_rope(keys, cos, sin)
        # ...

作用

  • 与 [[Post-Norm vs Pre-Norm|Post-Norm]] 一起 → 稳定训练
  • QK 的尺度被显式控制 → 防止 attention logits 爆炸

谁在用

  • OLMo 2（首次出现在主流 LLM）
  • Gemma 2 / Gemma 3
  • MiniMax M2（Per-Layer QK-Norm——见下）
  • Arcee Trinity Large
  • GLM-4.5
