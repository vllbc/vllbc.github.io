Self-Guided Function Calling in Large Language Models via Stepwise Experience Recall

vllbc 发布于 2025-08-23 收录于 Agent Reading

比context_engineering更高级的经验学习。从经验池中检索相似的经验来指导agent。

论文深度解读

这篇论文的核心目标是解决大型语言模型（LLM）在执行多步骤、复杂工具调用（Multi-step Function Calling） 任务时遇到的一个根本性瓶颈：如何高效、动态地从过去的经验中学习，以应对新问题？ 传统的解决方案，如上下文学习（In-context Learning, ICL），通常依赖于在提示（Prompt）中提供一些固定的、人工筛选的示例（Few-shot Examples）。然而，这种方法存在三大问题： 1. 静态性与局限性：示例库是预先定义好的，无法适应模型在使用过程中遇到的新情况和新工具。 2. 检索粒度粗糙：传统的检索方法通常只基于用户初始问题的语义相似度来寻找示例，但这对于需要复杂工具链协作的任务来说远远不够。一个任务的解决路径（即工具的调用顺序和方式）可能比其初始描述更具参考价值。 3. 扩展性差：随着工具数量和任务复杂度的增加，手动编写高质量的示例变得极其困难且成本高昂，无法规模化。

论文深度解读：从“可验证”到“可度量”的范式革命

当前，以强化学习（Reinforcement Learning）为核心的对齐技术，特别是基于可验证奖励的强化学习（Reinforcement Learning from Verifiable Rewards, RLVR），已成为驱动顶尖大模型（如OpenAI的GPT系列、DeepMind的Gemini系列）能力飞跃的关键引擎。RLVR的核心思想是，利用那些模型难以生成但易于验证的任务来进行训练。例如，在数学题中，模型可能很难直接得到正确答案，但验证一个答案是否正确（比如通过对比标准答案）却非常简单；在代码生成中，执行单元测试（Unit Test）就能客观地判断代码的正确性。这种范式极大地推动了模型在逻辑推理、数学和编程等领域的能力。
