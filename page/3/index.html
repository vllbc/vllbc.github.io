Latent Experts

vllbc 发布于 2026-06-06 收录于 LLM MoE

Latent Experts

来自 Sebastian Raschka 的 The Big LLM Architecture Comparison。

一句话

Latent Experts = MoE 中的专家在 latent space（低维） 工作，而非原始 token embedding 空间：

  • 输入 4096 维 down-project 到 1024
  • 专家在 1024 维工作
  • 输出 up-project 回 4096

→ 节省计算量，专家可以更”小”。

Llama 4

vllbc 发布于 2026-06-06 收录于 LLM LLM Architecture Model

Llama 4 Maverick

原文第 5 节。Llama 4 用 MoE，结构上与 DeepSeek V3 很像，但选择不同。

关键设计

Llama 4 Maverick 整体骨架与 DeepSeek V3 类似，但有这些显著区别：

维度 DeepSeek V3 Llama 4 Maverick
总参数 671B 400B
激活参数 37B 17B
注意力 MLA GQA
MoE 模式 9 专家（每专家 hidden 2048） + 1 共享 2 专家（每专家 hidden 8192）
MoE 放置 每层（除前 3 层） 隔层（dense / MoE 交替）

也就是说 Llama 4 Maverick 走”少量大专家”路线，DeepSeek V3 走”大量小专家 + 共享”路线。
