Beyond Ten Turns：Unlocking Long-Horizon Agentic Search with Large-Scale Asynchronous RL

vllbc 发布于 2025-08-15 收录于 Agent Reading

提出了一个异步框架，来解决长尾分布问题，并且创新了一种数据合成的方式，注入和模糊化问题。

这篇论文的核心目标是解决当前开源大型语言模型（LLM）在执行复杂、长周期的搜索任务时能力不足的问题。在当今世界，我们越来越依赖AI智能体（Agent）来解决需要深度探索和信息整合的知识密集型任务。例如，不仅仅是简单地回答“法国的首都是哪里？”，而是去解决“根据公开财报和新闻，分析苹果公司在2024年第四季度的供应链风险，并总结主要影响因素”。这类任务需要智能体具备我们称之为“搜索智能”（Search Intelligence）的能力——即能够理解模糊的查询、设计精确的搜索策略、从充满噪声的海量信息中提取关键数据、解决信息冲突，并进行持续深入的探索。

Sample More to Think Less：Group Filtered Policy Optimization for Concise Reasoning

vllbc 发布于 2025-08-15 收录于 LLM-RL Reading

压缩cot的工作，类似LAPO：INTERNALIZING REASONING EFFICIENCY VIA LENGTH-ADAPTIVE POLICY OPTIMIZATION，这篇叫做GFPO。

这篇论文直面了当前大模型领域一个非常棘手且普遍的问题：在通过强化学习（Reinforcement Learning）进行对齐训练时，模型为了追求更高的奖励（reward），往往会产生越来越长、越来越啰嗦的回答。这种现象被称为“长度膨胀”（Length Inflation）。尽管更长的回答在处理复杂问题时有时是必要的，但很多时候模型只是在生成重复、冗长的“填充性”文本，这不仅极大地增加了推理的计算成本和延迟，有时甚至会因为引入过多无关信息而降低回答的准确性。

Empowering Large Language Model Agents through Action Learning

vllbc 发布于 2025-08-12 收录于 Planning Reading

迭代式生成并评估新的动作，也就是将多个函数包装成一个函数，想法很有趣。

论文深度解读

这篇论文的核心论点是：当前大模型智能体（LLM Agents）的潜力被其固定的、预先定义好的“动作空间”（Action Space）所严重限制。智能体就像一个工匠，而动作空间就是它的工具箱。如果工具箱里只有锤子和螺丝刀，那么无论工匠多么聪明（LLM的推理能力有多强），他都很难完成需要电钻或扳手的复杂任务。现有的方法，如著名的ReAct或Reflexion，更多地是在教工匠如何“更好地思考”如何使用现有工具，而这篇论文则另辟蹊径，致力于让工匠学会“自己制造和打磨新工具”。

Memp：Exploring Agent Procedural Memory

vllbc 发布于 2025-08-12 收录于 Agent Reading

改进了agent中的记忆模块

论文深度解读

这篇发表于2025年8月的论文，聚焦于为基于LLM的Agent赋予一种程序化记忆（Procedural Memory）。这个概念源于认知科学，指的是我们“如何做某事”的记忆，例如骑自行车或打字，一旦学会便可自动执行，无需有意识地思考每一步。作者将此概念巧妙地迁移到AI Agent领域，旨在解决一个普遍存在的问题：尽管LLM Agent在处理多样化任务上表现出色，但它们往往缺乏从经验中学习并形成稳定“技能”的能力。每当遇到一个新任务，即使与之前的任务高度相似，它们也常常需要从头开始探索，导致效率低下和成功率不稳定。
